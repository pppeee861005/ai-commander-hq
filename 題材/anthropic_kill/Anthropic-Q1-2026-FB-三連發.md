Zapier、Make.com、n8n、UiPath 這些價值數十億美元的自動化平台，正在被一場精心設計的三步戰役絞殺。

## 【中篇】Zapier 自己把刀遞給 Anthropic 的那一刻

接續上篇——

如果第一步 Cowork 是地基破壞，第二步 Enterprise Plugins 是部門級狙擊，那第三步 Skills 開放標準就是整個生態的絞殺。

🎯 Anthropic 的陽謀是這樣運作的：

2 月 24 日發布的 Plugins，直接內建：
▪️ 財務部門代理（市場研究 + 財務建模）
▪️ 法務部門代理
▪️ HR 部門代理（職缺描述 + 入職材料 + offer letter）

這些正是 UiPath 賣了十年的 RPA 核心場景。

但真正的殺招在這裡——

Skills 開放標準的啟動合作夥伴名單：

Zapier、Figma、Canva、Stripe、Notion、Atlassian、Cloudflare、Vercel、Ramp、Sentry

看出來了嗎？

⚡ Zapier 自己是 Skills 的合作夥伴。

它親手把自己的 workflow know-how 變成了 Claude 的內建能力。結果呢——Zapier 付費用戶發現：

「我為什麼要付錢給 Zapier？我直接叫 Claude 幫我跑 cron job 不就好了？」

這就是 Claude Code Routines 在做的事：

自動化任務直接在 Anthropic 雲端跑，連電腦關機都不影響。

📊 同時期的數字：
▪️ Claude Code 年化收入 25 億美元（11 月才 10 億）
▪️ Anthropic G 輪融資 300 億美元
▪️ 估值 3800 億美元，全球第三大私人公司

Anthropic 不需要自己做 Zapier。它讓 Zapier 變成 Claude 的一個 feature。

這才是真正的 SaaSpocalypse。

下篇進入最有意思的部分——設計賽道的洗牌，以及超級個體的真正機會。

## 【下篇】Claude Design × GPT Image 2：設計師被洗牌後，真空位在哪？

終章來了——

4 月份兩週內，Anthropic 和 OpenAI 同時對設計賽道出手：

🎨 Claude Design（4/17）
▪️ 非設計師描述需求 → 產出原型 / 簡報 / 一頁式
▪️ 讀取企業 design system，自動套用品牌
▪️ 輸出 HTML / PDF / PPTX

🖼️ GPT Image 2（4/21）
▪️ 2K 解析度 + 原生推理
▪️ 印刷級文字渲染（菜單不再拼錯字）
▪️ 一次生成 8 張角色一致的圖像

兩家的策略不一樣：

▪️ Claude 切「工作流」——讓不會設計的人直接交付成品
▪️ GPT Image 2 切「像素」——讓設計師的生產速度 10 倍

中階設計師的位置被壓扁了。

但這裡有真正的機會——

💡 超級個體的三條切入路徑：

1️⃣ AI 原生設計代理

拿 Claude Skills + 自己的垂直領域 know-how（例如 CAD、建築、室內設計），做成訂閱制代理服務。

2️⃣ 台灣在地化品牌代理

繁體中文 + 台北市場 = Anthropic 和 OpenAI 的絕對盲區。

用 GPT Image 2 API 包裝成台灣中小企業的品牌套組服務。

3️⃣ Design System 顧問

企業需要把視覺規範「翻譯」成 AI 可讀的 Skills 套件。這是 6-12 個月的過渡期黃金窗口。

🎯 核心洞察：

當 Claude Design + GPT Image 2 把「設計執行層」商品化，真正值錢的變成：

▪️ 領域 know-how 的 Skills 封裝
▪️ 在地市場的語境轉譯
▪️ 企業 Design System 的 AI 化顧問

這三個位置，Anthropic 和 OpenAI 都吃不到。

因為他們做平台，不做地區。他們做通用，不做垂直。

🧠 最後留一個問題給大家：

Zapier 用 Claude 讓自己變強，結果變成 Claude 的一個 feature。

當我們用 AI 讓自己變強，我們會不會變成誰的 feature？

答案取決於——你是在賣時間，還是在賣資產。
