## 序言：為什麼舊故事只說了一半

你讀過《變革的前奏》了。故事很精彩，刀刀致命。但它只回答了一個問題：

## 第一部分｜認識兩個競爭的引力井

### SaaS 時代的舊引力井（2015-2025）

Zapier、Figma、Canva、UiPath 這群公司靠什麼贏了十年？

用引力理論解釋，它們各自建立了強大的**專業化引力井**：

```
                    ┌──────────────────┐
                    │   Zapier 引力井   │
                    │                  │
                    │ 「連接的黑箱」    │
                    │ API 生態鎖定    │
                    └────────┬─────────┘
                             │
              ┌──────────────┼──────────────┐
              ↓              ↓              ↓
         Slack       HubSpot      Salesforce
         Gmail       Airtable     Jira
         ...         ...          ...

    [數百個 SaaS 互相冷淡，只透過 Zapier 通話]
```

**Zapier 的引力井有多深？**

- **資料鎖定**：你的工作流定義存在 Zapier 伺服器
- **轉移成本**：遷移 500 個 Zap 需要重新配置、需要工程師
- **API 壟斷**：Zapier 掌握了各服務商的 API 說明書
- **抽稅率**：每個月 $20-$600，客戶無法議價

**這個引力井有多穩定？**

理論上來說，只要 A) Zapier 的工作流還有效，B) 集成 API 還在更新，C) 客戶習慣沒改變——引力場就會永遠存在。

Zapier 本身也這樣相信。2024 年還在融資、還在擴張。

然後 2 月 25 日，一個新的**超級引力井**出現了。

---

### AI 時代的新引力井（2026 起）

Cowork 發布那天發生了什麼？

```
                    ┌──────────────────┐
                    │  Claude 引力井    │
                    │  「通用推理黑箱」 │
                    │ 理解 × 執行      │
                    └────────┬─────────┘
                             │
              ┌──────────────┼──────────────┐
              ↓              ↓              ↓
         Slack       HubSpot      Salesforce
         Gmail       Airtable     Jira
         **以及所有未來的 SaaS**

    [不需要 Zapier，Claude 直接理解意圖並執行]
```

**Claude 的引力井有多深？**

- **資料不鎖定**：指令是自然語言，不依賴專有格式
- **轉移成本**：切換到 ChatGPT 或其他 AI，只改一個 provider
- **API 冗余**：就算某個 API 停止，Claude 還能「視覺看、點擊做」（Computer Use）
- **抽稅率**：$20 Claude Max 訂閱，無限工作流，實際成本近乎免費

**更關鍵的是——引力方向改變了。**

在 Zapier 時代：
```
用戶 → Zapier（自己控制流程定義）→ Zapier 說怎麼做，SaaS 就怎麼做
```

在 Claude 時代：
```
用戶 → Claude（AI 理解意圖）→ Claude 自己決定怎麼做，直接操作 SaaS
```

**引力的來源從「流程中介」變成了「通用推理」。**

這不是簡單的競爭升級。這是**引力井的物理性質完全改變**。

## 第二部分｜引力洩漏的發生

### 何謂「引力洩漏」？

白皮書說：

> 當一個平台的引力場開始衰減（演算法改動、用戶流失、商業模式失效），所有依附其上的資產同時崩潰。

Zapier 的引力洩漏有什麼不同？

不是漸進式衰減，是**結構性摧毀**。

### 洩漏發生的物理過程

**第一階段｜認知衝擊（2/25-3/19）**

```
CEO 看到 Cowork 新聞
    ↓
「等等，AI 可以直接做到我們做的事？」
    ↓
立刻明白：我們的抽稅率無法與 Claude Max 競爭
    ↓
開始計算：如果客戶都用 Claude，Zapier 的 TAM 縮小 90%
    ↓
引力場強度下降
```

Zapier CEO 的股票拋售，不是巧合——是**資訊優勢導致的市場信號**。他比市場更早看到引力洩漏已經開始。

**第二階段｜客戶離開（持續中）**

```
「我現在用 Claude 免費做工作流」
    ↓
「為什麼還要付 Zapier 的錢？」
    ↓
遷移痛點 < 成本節省
    ↓
用戶大規模流失
    ↓
引力場快速衰減
```

**第三階段｜生態坍塌（未來 6-12 個月）**

```
一旦用戶流失超過 30%
    ↓
Zapier 收入下降
    ↓
無法投入 R&D 競爭 Claude
    ↓
產品差距越來越大
    ↓
更多用戶流失
    ↓
死亡螺旋
```

這不是商業競爭。這是**物理級別的引力場坍塌**。

## 第三部分｜四刀為什麼必然命中

### 第一刀：Cowork 為什麼殺死 Zapier

用引力理論的語言：

**Zapier 的引力來源 = 「流程中介」**

Cowork 的出現直接摧毀了這個引力源。

```
引力來源被摧毀
    ↓
引力場強度 → 0
    ↓
軌道客戶開始逃逸
    ↓
必然死亡
```

**為什麼 Zapier 無法反擊？**

因為反擊需要：
1. AI 推理能力（需要 20 年的 R&D）
2. 資料優勢（Zapier 的資料是結構化配置，不是推理語料）
3. 優先級高於現有業務（董事會不會同意砍掉現有 SaaS 営業去做 AI）

Zapier 本質上被困在了舊引力井——**它的競爭力是為舊世界服務，卻無法為新世界重生**。

### 第二刀：Dispatch 為什麼殺死 BPO

用引力理論的語言：

**BPO 工廠的引力來源 = 「人力成本套利」**

Dispatch 直接摧毀了這個套利的可行性。

```
菲律賓勞工 × $800/月 的成本優勢
    ↓ 遇到
Claude Max × $20/月 的成本優勢
    ↓
成本套利蒸發 95%+
    ↓
BPO 模式的引力場完全消失
```

**為什麼 BPO 工廠無法轉型？**

因為它們的資產結構全部對應「人力」：
- 大樓（針對 1200 人）
- 管理層（針對生產線管理）
- 訓練體系（針對新進員工）
- 人力成本結構

AI 出現後，這些資產全部變成**負債**。它們無法快速轉身——物理上就轉不了。

### 第三刀：Computer Use 為什麼繞過所有 API 護城河

用引力理論的語言：

**所有 SaaS 的防守引力 = 「API 只給付費方」**

Computer Use 直接繞過了這個防守。

```
SaaS 廠商說：「只有集成 API 的人才能自動化」
    ↓
Claude 說：「我不需要你的 API，我看螢幕、點按鈕」
    ↓
API 護城河完全失效
    ↓
無護城河 = 容易被替代
```

**為什麼這一刀特別致命？**

因為它不只是殺死某一個 SaaS，而是**摧毀了整個 SaaS 時代的根本防守邏輯**。

過去 15 年，SaaS 的生存邏輯是：
> 「鎖住 API，就鎖住了客戶的遷移成本。」

Computer Use 證明了這個邏輯已死。

### 第四刀：Claude Design 為什麼殺死 Figma

用引力理論的語言：

**Figma 的引力來源 = 「協作設計的集中點」**

Claude Design 直接摧毀了這個引力源。

```
設計師都要在 Figma 工作，因為那是唯一的協作工具
    ↓
Claude Design 出現：「誰說一定要 Figma？我直接生成設計稿」
    ↓
Figma 從必需品變成可選品
    ↓
引力場強度劇烈下降
```

**更致命的部分是什麼？**

Figma 最害怕的不是「被替代」，而是**使用者的根本任務改變了**。

過去的工作流：
```
想法 → Figma 設計 → 設計檔交付 → 開發者實現（3 週）
```

Claude Design 的工作流：
```
想法 → 一句話 → Claude 生成 → Claude Code 實現（1 小時）
```

Figma 被需要的根本理由消失了。這是**引力消滅**（不是引力衰減）。

## 第四部分｜為什麼說「第五波」會更狠

### 現象：垂直行業的引力重構

第五波（Q3 2026）的目標是什麼？

**中產白領初階職位的系統性替代**

用引力理論解釋，這相當於：

```
新引力井出現：Claude for Legal、for Finance、for Healthcare

舊引力井開始洩漏：
  ├─ 初階律師助理的工作被 Claude Legal 接走
  ├─ 初階會計師的工作被 Claude Finance 接走
  └─ 初階醫療行政被 Claude Healthcare 接走

受影響人口：全球數百萬知識工作者
失業時間：6-12 個月內大規模陣痛
```

**這比前四刀更深的原因是什麼？**

因為它不只是摧毀一個產品、一個平台、一個產業，而是**摧毀一整套教育-就業的引力場架構**。

```
傳統路徑的引力：
  ├─ 讀律師系（投入 4 年）
  ├─ 當律師助理（3-5 年薪資學習）
  ├─ 升到律師（薪資 ↑ 100%）
  └─ 成為合夥人（薪資 ↑ 300%）

新引力的出現後：
  ├─ 讀律師系的 ROI 變負（Claude Legal 直接做律師助理的工作）
  ├─ 律師助理職位消失 90%
  ├─ 一部分人永遠無法升到「律師」
  └─ 整個行業的薪資結構崩潰
```

**引力洩漏的受害者，不再是公司，而是整個職業的中堅人口。**

## 第五部分｜超級個體的真正機會在哪

### 誤解：「我可以用 AI 做自由職業」

這個想法在引力理論上會失敗，原因很簡單：

```
你做律師助理工作（用 Claude Legal）
    ↓
客戶想要律師助理工作（很便宜）
    ↓
Claude Legal 也在做同樣工作（免費）
    ↓
你被吸進 AI 引力井
    ↓
淘汰
```

**你用 AI 做的工作，本質上就是在「幫 AI 驗證價值」，而不是在建立自己的引力場。**

### 真正的機會：引力井的重新佈局期

在舊引力場完全坍塌、新引力場還沒完全定型的窗口期（未來 6-18 個月），有三種人能活下來：

**第一類｜引力轉譯者**

當 Claude Legal 出現時，它做的是「通用法律助理」。

但一個特定行業（比如：台灣醫療法律）的律師事務所，需要的是「理解台灣法規 × 醫療語境」的 Claude。

```
機會：
  Claude for Legal（通用引力井）
        ↓ 需要行業知識翻譯
  自己的 Legal Agent（垂直引力井）
        ↓ 只有你能做到的轉譯
  簽約律師事務所（付費客戶）
```

**你不是在「用 AI」，而是在「用引力理論建立自己的微型引力井」。**

**第二類｜引力多元化者**

當某個行業被 Claude 摧毀時，那個行業的資深人才面臨選擇：

1. 死守舊職位（必敗）
2. 轉職到其他行業（被新手搶飯碗）
3. **建立自己的 Hub，吸收從舊引力井逃逸出來的人才**

```
律師助理失業 → 尋找知識轉移路徑
  ↓ 發現你的 Blog + Email
  ├─ 分享「如何在 AI 時代重生」
  ├─ 每週發 Hub 長文
  ├─ 每月發售 Skill（$99 的「AI 律師助理養成指南」）
  └─ 累積訂閱者 → 賣課程、代理服務 → 年收破百萬
```

**你沒在「做工作」，而在「做轉移引力的通道」。**

**第三類｜引力保衛者**

某些工作無法被 AI 完全替代，但會被 AI 大幅改變。

比如：設計師（Claude Design 出現後，初階設計師死了，但資深創意總監的需求反而上升）

```
設計工作流改變：
  設計執行層 ← Claude Design 接走 80%
  設計策略層 ← 人類反而更值錢（因為 AI 無法做策略）

超級個體的做法：
  ├─ 建立 Hub（深度設計策略思想）
  ├─ 公開「如何用 Claude Design + 人類創意超越 Figma」
  ├─ 吸收流離失所的初階設計師當學徒
  ├─ 賣「策略設計 Agent」給企業（年費 $50K）
  └─ 用 AI 工具，但用人類智慧定價
```

**你沒在「競爭」，而在「重新定義職業的邊界」。**

## 第六部分｜超級個體的引力戰略實戰

### 如何在「引力反轉期」建立自己的引力井

#### Step 1：辨識「逃逸的資料流」（未來 3 個月）

四波攻擊會摧毀四個產業，釋放出數百萬被迫逃逸的人才資料。

```
Zapier 倒下 → 自動化工程師逃逸
  ├─ 他們需要：「如何把自動化知識轉移到 AI 時代」
  └─ 你的機會：寫 Blog 說「Zapier 工程師轉型指南」

Figma 衰退 → 設計師逃逸
  ├─ 他們需要：「如何和 Claude Design 協作而非競爭」
  └─ 你的機會：寫 Blog 說「設計師的 AI 時代生存指南」

BPO 崩潰 → 數據處理工人逃逸
  ├─ 他們需要：「怎樣用 Dispatch 重新找到工作」
  └─ 你的機會：寫 Blog 說「低技能工作者的 AI 轉型」
```

**你要做的不是「寫給 CEO」，而是「寫給被時代拋下的人」。**

因為他們正在被大規模吸進一個新的引力井，而他們最缺的就是**轉譯者**。

#### Step 2：建立雙星系統（未來 3-6 個月）

用引力理論的標準配置：

```
           ┌─────────────┐
           │  你的 Hub    │
           └─────┬───────┘
                 │
        ┌────────┴────────┐
        ↓                 ↓
    [ Blog ]          [ Email ]
    (被動流量)        (主動觸達)
    ← SEO 累積        ← 訂閱複利
    ← 被引用          ← 信任累積
```

**重點不是「寫好內容」，而是「等待引力複利啟動」。**

根據第三定律，18 個月後，你的 Hub 會成為「流離者的燈塔」。

#### Step 3：轉化引力為商業（6-18 個月）

```
Blog 訪客逐漸增長
    ↓ 18 個月後達到臨界點
Email 訂閱者破萬
    ↓ 他們信任你
推出第一個 Skill（$99）
    ↓ 「Zapier 工程師的 Claude 自動化工具包」
銷售 $10K
    ↓ 驗證了產品市場匹配
推出第一個 Agent（年費 $999）
    ↓ 「為你的行業定製的 Claude Agent」
簽約 50 個企業客戶
    ↓ 年收 $50K
推出第二、第三個 Skill
    ↓ 年收破百萬
```

**但前提是——你從現在開始就建立 Hub，而不是等到引力複利啟動才後悔。**

#### Step 4：成為「新引力井」（18 個月後）

到這個階段，你已經不是「自由工作者」，而是**自己的引力中心**。

```
你的 Hub 有 5 萬訂閱者
    ├─ 他們信任你
    ├─ 他們引用你的思想
    ├─ 他們買你的 Skill 和 Agent
    └─ 新的逃逸者自動被吸進你的軌道

你變成了「人力資源的新引力井」
    └─ 被舊時代淘汰的人，自動流向你

這時候才是「用 AI 做商業」的真正開始
    └─ 因為你有引力，不怕 AI 競爭
```

## 第七部分｜終局：三種人的命運

### 2026 年的三條岔路

#### 岔路一：只用 AI 的人（必敗）

```
「我用 Claude 做律師助理工作」
    ↓
你的服務 = Claude Legal 的薄包裝
    ↓
客戶發現可以直接用 Claude，價格 1/10
    ↓
淘汰
```

**終局：變成 AI 的時薪員工，競爭對象是全球勞動力，薪資被壓到無法生活。**

#### 岔路二：躲進傳統職位的人（部分敗）

```
「我就守著律師職位不放」
    ↓
助理職位被淘汰 → 你面臨「做助理的工作」才能活下來
    ↓
一部分人轉型成功（建立自己的 Hub）
    ↓
一部分人沉沒（無法跳出舊引力井）
```

**終局：取決於你轉身的快度。早轉的人建立了新引力井；晚轉的人被競爭淹沒。**

#### 岔路三：建立 Hub 的人（大概率勝）

```
「我現在就開始寫 Blog、建 Email 名單」
    ↓ 前 6 個月：很慢，沒什麼流量
    ↓ 6-18 個月：指數增長，複利啟動
    ↓ 18 個月後：成為某個逃逸者群體的「燈塔」
    ↓ 年收開始變化：$100K → $500K → $1M+
    ↓ 最關鍵的：你變成了「別人無法替代的引力中心」
```

**終局：成為超級個體，建立屬於自己的引力場。**
