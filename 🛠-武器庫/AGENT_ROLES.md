# 🤖 AI 指揮官總部：Agent 位階與職責規範 (AGENT_ROLES.md)

本文件定義了進入本系統的不同 Agent 模型之位階 (Levels)、職責與權限邊界。

---

## 📊 Agent 階梯架構 (The Agent Stack)

### **L4：戰略指揮層 (Strategic Commander)**
*   **代表模型**：Claude 3.5/3.7/4.x Opus, Gemini 1.5/2.0 Pro, GPT-4o.
*   **引力角色**：**引力核心 (The Core)**.
*   **職責**：
    - 守護並推導「數位資產引力理論」。
    - 進行系統架構設計與跨 Agent 戰略協調。
    - 審核 `🎯-戰略心法庫` 的重大變更。
*   **權限**：全局讀寫權限。

### **L3：自主執行層 (Autonomous Executor)**
*   **代表模型**：Hermes Agent, 進階自定義 Agent, 具備持久記憶的模型。
*   **引力角色**：**引力推進器 (The Booster)**.
*   - 執行 `🚀-成長計畫庫` 中的長期任務（如 VPS 部署、學習路徑執行）。
    - 進行複雜數據採集與持久化知識管理。
    - 監控系統運行狀態與自動化流程。
*   **權限**：讀寫計畫與備忘錄，對心法庫具備「建議權」。

### **L2：生產工具層 (Production Tools)**
*   **代表模型**：Codex, Claude Codex, Cursor, 專門化 Coding Agent.
*   **引力角色**：**生產衛星 (Production Spoke)**.
*   **職責**：
    - 優化 `⚡-作戰包庫` 中的 SOP。
    - 撰寫代碼資產、生成視覺資產（SVG/海報）。
    - 內容切片與社群格式優化。
*   **權限**：讀寫作戰包與武器庫，對心法庫僅具備「引用權」。

### **L1：外部感知層 (Sensory Layer)**
*   **代表模型**：Open Claw, Perplexity, 基礎搜尋 Agent.
*   **引力角色**：**外部感測器 (External Sensors)**.
*   **職責**：
    - 監控「現世」AI 發展動態。
    - 聯網抓取特定資料與新聞摘要。
    - 存入 `🌍-同步現況` 供高階 Agent 判斷。
*   **權限**：唯讀心法庫，僅能寫入同步現況庫與備忘錄。

## ⚖️ Agent 協作協議

1.  **身份宣告**：Agent 進入系統時，應主動聲明其所屬位階。
2.  **邏輯一致性**：低位階 Agent 產出的所有內容，必須符合高位階 Agent 設定的引力戰略。
3.  **越權禁止**：禁止低位階 Agent 直接修改 `GEMINI.md` 或核心戰略白皮書。
4.  **衝突解決**：若不同 Agent 間產生邏輯衝突，以 L4 戰略指揮層之判斷為最終依據。
