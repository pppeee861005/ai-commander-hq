三、Agent 成長軌跡時間線 (2023-2026)

### 🏺 古代：Chat Bot 時代 (2023 - 2024 上半)
- **核心特徵**：被動回答、單次對話、無環境互動。
- **工作流**：人類想 prompt → AI 回答 → 人類複製貼上。
- **侷限性**：AI 只是「會說話的百科全書」，沒有手腳，無法對現實世界產生連鎖反應。

### 🚀 現代：Agent 時代 (2024 下半 - 現在)
- **核心特徵**：**主動規劃、目標驅動、工具調用、環境反饋**。
- **工作流**：指揮官給出「目標 (Goal)」→ Agent 拆解步驟 (Plan) → 自主使用工具執行 (Act) → 根據結果修正 (Loop)。
- **本質變化**：AI 從「對話框」進化為「數位勞動力」。它不再只是回答問題，而是「完成任務」並「維護資產」。

能力:多工具協作、初步自主規劃
工作流:給目標 → AI 拆解 → 多步驟執行
代表:Claude 3, AutoGPT, Devin 早期
設計師案例:AI 能寫腳本 + 解釋 + 偵錯,但不能直接操控軟體

2025 年:Agent 平台化時代

能力:Skills 系統、長 context、MCP (Model Context Protocol)
工作流:AI 透過外掛與插件(Skills, CLI) 呼叫外部工具。
代表:Claude Skills, OpenAI GPTs, MCP 協議。

2026 年+:能力內化時代 (Native Agency)

能力:LLM 原生具備工具操作本能,不再需要「外掛」補位。
趨勢:目前的 Skill、CLI、MCP 將被內化為 LLM 的「基本功」。
設計師案例:不用裝 Bonsai BIM 外掛,Claude 本身就讀得懂 IFC 標準並能直接輸出 .blend。
戰略警示:「工具型 Skill」將迅速折舊,護城河向「責任」與「專有資料」收縮。
