三、Agent 成長軌跡時間線(2023-2026)
2023 年:Prompt 時代

能力:單次對話、單次回答
工作流:人類想 prompt → AI 回答 → 人類複製貼上
代表:ChatGPT 初代、Claude 1.0
設計師案例:寫一段 Ruby 腳本,自己貼到 SketchUp 跑

2024 年初:工具呼叫時代

能力:Function Calling、單一工具使用
工作流:AI 會用搜尋、會跑程式碼、但仍是被動觸發
代表:GPT-4 Turbo、Claude 2.1
設計師案例:AI 能解釋 Ruby 腳本錯誤,但不能自己跑

2024 下半:Agent 雛形時代

能力:多工具協作、初步自主規劃
工作流:給目標 → AI 拆解 → 多步驟執行
代表:Claude 3, AutoGPT, Devin 早期
設計師案例:AI 能寫腳本 + 解釋 + 偵錯,但不能直接操控軟體

2025 年:Agent 平台化時代

能力:Skills 系統、長 context
