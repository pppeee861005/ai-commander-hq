# 寫作心法

你的寫作風格和方法論。

## 核心原則

### 1. 清晰勝於華麗
- 一句話只表達一個完整意思
- 避免過度修飾詞
- 讀者應能一遍讀懂

### 2. 故事先於理論
- 用具體例子開場
- 數據支撐論點
- 邏輯自然推導

### 3. 價值優先於數量
- 寧要一篇深度文章，不要十篇淺嘗
- 每篇都應有可操作的洞察
- 讀者讀完應有收穫

## 寫作框架

### 三段論結構
```
開場：
- 引起共鳴或好奇
- 說明為什麼重要
- 預告核心觀點

中段：
- 詳細解釋核心觀點
- 舉 2-3 個具體例子
- 逐步深化認知

結尾：
- 總結核心洞察
- 提出可實踐的建議
- 邀請思考或行動
```

### 開場公式

選擇一種方式開場：

| 方式 | 例子 | 適用場景 |
|------|------|---------|
| **問題式** | 「你有沒有想過...」 | 激發思考 |
| **故事式** | 「有一個朋友曾經...」 | 建立共鳴 |
| **數據式** | 「最近的研究發現...」 | 增加可信度 |
| **反轉式** | 「大多人都認為...實際上...」 | 打破既有認知 |
| **直接式** | 「今天我想聊...」 | 建立親密感 |

## 表達技巧

### 讓文章更有張力

1. **對比法**
   - 對錯對比：錯誤的方式 vs. 正確的方式
   - 前後對比：之前 vs. 之後
   - 因果對比：如果不做會怎樣 vs. 做了會怎樣

2. **列舉法**
   - 使用 ✨ 🔥 💡 等符號
   - 用數字列出關鍵點（如：3 個習慣、5 個步驟）
   - 創造視覺停頓

3. **比喻法**
   - 「就像...一樣」
   - 用讀者熟悉的事物解釋陌生概念
   - 建立心理橋樑

### 句式多樣化

避免單調感：

```
短句造成戰速感。
長句用於解釋複雜概念，提供更多層面的理解和上下文。
問句制造互動："你試過嗎？"
```

## 內容審核清單

發佈前檢查：

- [ ] **準確性**：所有數據和引用都正確
- [ ] **清晰性**：讀者能輕鬆理解主要觀點
- [ ] **可操作性**：讀者讀完知道下一步做什麼
- [ ] **一致性**：語氣、邏輯、例子都一致
- [ ] **完整性**：有開場、中段、結尾，結構完整
- [ ] **吸引力**：標題和開場足夠吸引人

## 常見陷阱與避免方法

| 陷阱 | 症狀 | 解決方案 |
|------|------|---------|
| **過度專業** | 讀起來像論文 | 加入對話式語言，減少行話 |
| **空洞無物** | 全是觀點，沒有例子 | 為每個觀點配一個具體例子 |
| **冗長拖沓** | 一個想法重複說多次 | 用「總結」開頭，快速推進 |
| **邏輯跳躍** | 讀者一下子跟不上 | 用「這意味著」等過渡語句 |
| **自說自話** | 忽視讀者感受 | 加入互動式問題，檢查假設 |

## 修改技巧

### 自我編輯流程

1. **首稿完成**：先寫完，不要邊寫邊改
2. **放置 24 小時**：距離會讓你看得更清楚
3. **粗改**：檢查邏輯和結構是否完整
4. **精改**：優化句式和表達
5. **終檢**：最後一遍檢查錯別字和格式

### 改進問題句式

如果你寫的是「很有意思」，問自己：
- 具體是什麼有意思？
- 為什麼讀者會覺得有意思？
- 能否用更具體的詞？

## 學習與迭代

### 定期檢查
- 每月看一遍舊文章，找出現在會改進的地方
- 追蹤讀者反饋，看什麼風格互動最高
- 閱讀優秀作者，學習新技巧

### 持續練習
- 每週至少寫 2 篇文章
- 嘗試新的框架和技巧
- 記錄什麼方式效果最好
