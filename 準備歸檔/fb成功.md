量化交易 龍蝦
牛牛 有出 openclaw 專用的量化交易技能包，你知道嗎?
好好笑
我昨天在看程式交易要怎麼寫：
那天我以為我在問一個技術問題
我打開戰略層，問它：「富途牛牛的 API 怎麼接？」它沒有回答我。
它反問我：「你接它，是要看行情，還是要程式化下單？」
這個反問救了我們三個月。
如果它直接給我教學，
我會跟著裝、跟著跑、跟著在三個月後盯著模擬盤的 +18% 切到實盤、然後在第四個月發現實盤 -23%。它沒讓我走那條路。
它把我從「想程式化下單」這個性感但危險的真空，
拉回到「學 Agent 架構」這個真實該做的事。這就是新人類聯盟的工作方式：人類負責提問與決策，戰略層負責反問與校準，執行層負責落地。養成日記第一篇上線了。
