# 📝 工作日誌庫

本目錄用於記錄 AI 指揮官的每日運作細節。透過每日日誌，我們能追蹤任務的顆粒度進度，並確保所有行動都與戰略心法保持對齊。

## 🌌 引力場角色：動力量測儀 (Momentum Tracker)
本庫負責記錄引力場的「切線速度」。如果週節奏是軌道，工作日誌就是每一秒的推進力。
- **Agent 職責**：每日結束前協助指揮官總結進度，並將未完成任務平滑轉移至隔日規劃。
