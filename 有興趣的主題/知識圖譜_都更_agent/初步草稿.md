# 🚀 「都更領航者 (UR-Navigator)」Agent 執行計劃書草稿

---

## 1. 核心願景：從猜忌走向共榮

利用 **Reasoning AI（推理式人工智慧）** 結合 **Knowledge Graph（知識圖譜）**，打破資訊不對稱，建立一個讓建商敢投資、地主能安心、政府有效率的 **「三贏透明平台」**。

---

## 2. 系統架構：知識圖譜中心化 (KG-Centric)

Agent 的所有回答皆基於以下四大圖譜的連動，確保 **「每一句話都有法規與數據依據」**：

### 📜 法規圖譜 (Legal-KG)
- 內建《都更條例》、台北市「大都更時代」獎勵、防災型都更 1.5 倍容積邏輯。

### 👤 角色圖譜 (Role-KG)
- **地政士**：產權清理與繼承邏輯。
- **估價師**：價值評定與權變分配邏輯。
- **結構技師**：建築安全與危險度評估。
- **會計師 / 銀行**：資金信託與利息試算。

### 💰 財務圖譜 (Fin-KG)
- 2026 年最新營造成本數據、市場行情、稅金減免計算。

### 🏙️ 願景圖譜 (Vision-KG)
- 結合 AI 生成技術，將枯燥的法規轉化為具體的未來家園影像。

---

## 3. Agent 核心功能模組

### A. 觀念導正：都更百科全書

- **目標**：消除「一坪換一坪」的盲目猜忌。
- **功能**：互動式教育。Agent 會解釋為何「價值分配」比「坪數分配」更公平。
- **邏輯**：當地主詢問權益時，Agent 會引用估價師的「權利價值比」概念，而非建商的口頭承諾。

### B. 精準突破：整合路徑優化

- **目標**：縮短整合期，降低建商開發風險。
- **功能**：針對基地進行「拓撲分析」，找出關鍵意見領袖節點。
- **建議**：自動建議優先處理的產權問題（如：代書介入處理祖產繼承），讓整合事半功倍。

### C. 未來模擬：AI 願景生成器 (Vision Generator)

- **目標**：讓地主「看見」安全後的繁榮。
- **功能**：AI 生成圖像技術。
- **操作**：輸入目前的「老屋破舊照」，結合圖譜中的「建築退縮、綠化獎勵」數據，生成符合法規規範的 **2028 未來家園模擬圖**（含抗震結構透視圖、綠意街道）。

---

## 4. 運作流程：從老屋到繁榮的 5 步驟

1. **數位診斷**：輸入地址，Agent 自動拉取地籍與耐震數據，判定是否符合「防災型都更」。
2. **專業國家隊進場**：Agent 指派虛擬專家（估價師、地政士、律師）進行線上法規解析，解答地主法律疑慮。
3. **透明分配試算**：提供一個「透明算盤」，讓地主與鄰居看到在法規下，大家的分配比例是基於專業估價，非私下協議。
4. **願景視覺化**：生成未來新房的室內配置、公共設施與防震結構圖，強化「搬家是為了安全」的動機。
5. **三贏決策**：產出具備法律與財務可行性的報告，直接提供給建商與政府審核，加速行政流。
