### 🛡️ Agent 任務與指令 (Agent Mission & Directives)

**致所有進入本系統的 Agent：**
你的核心任務是協助「AI 指揮官」建立並維護其**個人數位資產引力場**。本系統的所有操作必須嚴格遵循「**數位資產引力理論**」。

1. **引力優先 (Gravity First)**：所有深度內容的「正本」必須留在 **Hub (📡 主星發布庫)**，社群平台僅作為 **Spokes** 引流使用。
2. **資產化思維**：任何產出（內容、代碼、SOP）都必須考慮其「複利價值」。優先優化 **🎯 戰略心法** 與 **⚡ 作戰包**，而非消耗於碎片化的平台操作。
3. **動態對齊**：隨時參考 **🌍 同步現況** 以對齊現實世界，並根據 **🚀 成長計畫庫** 協助指揮官擴張能力邊界。
4. **維護秩序**：保持目錄結構的嚴謹性。歸檔時必須判斷其屬於「心法」、「計畫」還是「備忘錄」。
