## 💡 使用指南

### 新增設計資產
1. 確認資產類型（品牌 / UI / 其他）
2. 放入相應子目錄
3. 更新本 README.md
4. 提交 git commit（前綴：`assets:`）

### 設計規範
- **品牌資產**：保留多種格式（PNG + SVG）
- **色卡**：標註 RGB / Hex / CMYK 值（如有）
- **命名規則**：中文 + 清晰描述（避免編碼名）

---

**核定層級**：L2 工具資產（可複用設計資源）
