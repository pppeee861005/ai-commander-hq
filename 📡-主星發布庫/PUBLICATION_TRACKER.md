## 🛠 發布工作流程

### Step 1️⃣：內容準備（2-3 週）
```
[ ] 確定選題
[ ] 搜集素材
[ ] 撰寫初稿（Google Docs 或 Markdown）
[ ] 自我編輯（邏輯、風格、長度）
[ ] 加入案例和引用
```

### Step 2️⃣：內部校審（3-5 天）
```
[ ] 檢查邏輯完整性
[ ] 驗證數據/引用準確性
[ ] 格式檢查（Markdown）
[ ] 讀一遍確保流暢
```

### Step 3️⃣：發布前準備（3-5 天）
```
[ ] Substack 排版
[ ] 生成社媒預告（3-5 條）
[ ] 製作封面圖（可選）
[ ] 規劃留言互動
[ ] 確定發布時間（通常 Wed-Thu 10am）
```

### Step 4️⃣：發布執行（1 天）
```
[ ] 在 Substack 正式發布
[ ] 發送訂閱者郵件
[ ] 在 Twitter/LinkedIn 分享預告
[ ] 回復讀者評論
```

### Step 5️⃣：發布後追蹤（持續）
```
[ ] 監控訪問量、互動
[ ] 回應讀者留言
[ ] 收集反饋
[ ] 優化社媒切片
```
