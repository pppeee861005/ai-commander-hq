# FB 引力貼文 SOP v1.0

發佈高互動引力主題貼文的標準流程。

## 目標
透過精心設計的文案和視覺，在 Facebook 上獲得高互動（點贊、評論、分享）。

## 前置條件
- [ ] 備有引力相關的圖片或視頻素材
- [ ] 已準備 2-3 個貼文文案初稿
- [ ] 了解目標受眾的核心關注點

## 步驟

### 1️⃣ 文案準備 (10 分鐘)

使用以下框架撰寫貼文文案：

```
【開場勾子】(引發好奇或共鳴)
很多人不知道...
你是否也...

【核心觀點】(清晰傳達主要訊息)
引力的本質是...
這意味著...

【實踐或反思】(可操作或引發思考)
試試看：
你的想法：

【行動召喚】(明確邀請互動)
留言告訴我：
轉發給...
```

### 2️⃣ 視覺搭配 (15 分鐘)

- [ ] 選擇/製作契合的圖片（建議 1200x628px）
- [ ] 確保文字清晰可讀
- [ ] 檢查色彩搭配是否吸引眼球

**色彩建議**：
- 背景：深藍色或黑色（高級感）
- 文字：白色或金色（對比度高）
- 強調色：橙色或黃色（引起注意）

### 3️⃣ 發佈前檢查 (5 分鐘)

- [ ] 文案是否有錯別字
- [ ] 句子是否流暢易讀
- [ ] 是否有明確的互動邀請
- [ ] 圖片是否上傳正確
- [ ] 標籤是否合適（#引力 #新人類）

### 4️⃣ 發佈 (2 分鐘)

- [ ] 選擇最佳發佈時間（通常是 18:00-21:00）
- [ ] 複製貼文文案
- [ ] 上傳圖片
- [ ] 發佈

### 5️⃣ 社群互動 (15 分鐘/每隔 2 小時)

發佈後的前 4 小時內：
- [ ] 每隔 30 分鐘檢查一次留言
- [ ] 快速回應前 5 個留言
- [ ] 讚美有深度的評論

## 文案模板範例

### 模板 A：問題式
```
你有沒有想過，為什麼有人總能吸引機遇靠近？

這不是運氣，而是「引力」。

就像地球有重力場一樣，每個人身上都有「引力場」。
你散發出什麼，就吸引什麼。

想像一下：
- 自信會吸引信任
- 價值會吸引資源
- 能量會吸引人脈

你現在的引力場在吸引什麼？

留言告訴我你的想法👇
```

### 模板 B：故事式
```
一個朋友曾經很迷茫，每天被生活打擊。

直到他發現一個秘密：改變自己的「引力場」。

他開始：
✨ 調整思維方式
✨ 優化日常習慣
✨ 清晰設定目標

3 個月後，他的人生開始改變。
機遇來敲門，貴人主動靠近。

這就是引力場的力量。

你想提升自己的引力場嗎？💫

轉發給身邊需要的人~
```

## 檢查清單

### 發佈前
- [ ] 文案字數在 50-150 字（最佳互動範圍）
- [ ] 至少有 1 個疑問句
- [ ] 至少有 1 個視覺素材
- [ ] 包含明確的 CTA（行動召喚）
- [ ] 已檢查拼寫和語法

### 發佈後
- [ ] 首 30 分鐘內已回應第一批留言
- [ ] 4 小時內互動回應率 >70%
- [ ] 標籤使用正確（最多 5 個）

## 常見問題

**Q: 最佳發佈時間是什麼時候？**
A: 晚上 18:00-21:00，特別是週三到週五。但最重要的是持續性，而不是完美的時間。

**Q: 貼文沒有互動怎麼辦？**
A: 檢查 CTA 是否足夠明確，或試試不同的開場句式。追蹤 Facebook Insights 看哪些類型互動最高。

**Q: 應該多久發一次？**
A: 建議每週 3-4 次，保持穩定但不過量。品質 > 數量。

**Q: 如何提高轉發率？**
A: 加入「轉發給...」的邀請，或提供對接收者有實際價值的內容。
